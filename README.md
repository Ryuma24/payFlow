# PayFlow

PayFlow is a Spring Boot project skeleton. Implementation and tests have been cleared so you can build the project from
the existing structure.

## Requirements

- Java 21 or later
- Maven 3.9 or later

## Project layout

- `src/main/java/com/payflow` — application source
- `src/main/resources` — application configuration
- `src/test/java/com/payflow` — test source
- `src/test/resources` — test configuration
